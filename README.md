# Гурман — знак и брендбук

Статичный сайт: три варианта знака и дизайна + брендбук по варианту 1 (монограмма «Г»).

- `index.html` — три варианта: состояния знака, упаковка (сырники 500 г + сырки 50 г трёх вкусов), симуляция полки, тест на дистанцию, сравнение, файлы.
- `brandbook.html` — брендбук: идея, построение и охранное поле, версии знака, цвет, типографика, тон, упаковка, носители, правила, файлы.
- `assets/` — векторные знаки (SVG, буквы в кривых), лок-апы, словесный знак.

Публикация: GitHub Pages (workflow `.github/workflows/pages.yml`).
